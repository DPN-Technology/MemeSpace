QUICK START
1. Download MemeSpace-@@TAG@@-Windows-Tester.zip from:
   https://github.com/DPN-Technology/MemeSpace/releases/tag/@@TAG@@
2. Extract the ZIP into a writable folder, such as Documents.
3. Install Node.js 24 or newer from https://nodejs.org/ if you don't already have it.
4. Double-click LAUNCH-MEMESPACE.cmd.
5. The first launch automatically downloads the exact @@TAG@@ source and
   installs locked dependencies. Internet access is required for first setup.
6. Your browser will open http://127.0.0.1:5173/ (refresh when the server is ready).
   Keep the launcher terminal open while testing.

OPTIONAL ADMIN TESTING
Run LAUNCH-CONTROL-CENTER.cmd in a separate window.
Open http://127.0.0.1:5174/.
Follow the first-run setup prompt in the admin terminal; there is no default
administrator password. Keep staff recovery codes private.
